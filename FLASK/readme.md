# Introduction to Flask

## Project Description

This project introduces the fundamentals of building web applications using Flask, a Python web framework.

## Requirements

- Python 3.12.11
- Flask 3.1.3
- Pipenv

## Getting Started

1. Navigate to the project directory:

   cd introFlask

2. Install the dependencies:

   pipenv install

3. Run the Flask application:

   pipenv run python app.py

4. Open your browser and visit:

   http://127.0.0.1:5000
